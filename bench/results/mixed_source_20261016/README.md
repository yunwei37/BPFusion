# Ordinary mixed-source integration

Actual root-source default8 protocol plus ordinary lifecycle qualification,
with separate normal Make8/16 build directories. See
[finding0068](../../../docs/findings/0068-mixed-source-integration.md).
No private source substitution or executable symlink replacement is used.
The Cu and replay module are byte-identical to the previously qualified mixed
candidate; Python changes only repository/library path discovery. Old
homogeneous/control sources/targets and the transport header are unchanged.

source_build.* and source_acceptance.* retain all commands, return statuses,
environment, real model revisions, exact source and default8 outcomes.
Protocol:four actual executors,2560 outcomes,93504 dual-replayed output tokens.
ordinary-summary.json describes all352 lifecycle outcomes including incomplete
cancels. Ordinary checks use a finite exact pre-observation output set;
unobserved cancels are not successful complete outputs or universal fidelity.
Kernel reply diagnostics truncate after128 records while all640 protocol
outcomes remain in client/replay evidence.

Large raw files are losslessly gzip compressed. For CPU-only replay, copy this
directory to an OS temporary directory, decompress its .gz sidecars there,
then run protocol_analysis.py qwen_source_protocol8.jsonl and the Smol equivalent.
Historical acquisition paths retain their actual TEMP names; ordinary portable
launch/client/cleanup commands are in docs/getting-started.md.
No new performance experiment is claimed by this engineering acceptance.
